# 공격자 격리

작성일: 2026-09-07

## 문제

공격자가 실제 웹에서 할 수 있는 것만 해야 한다. 그런데 기준선과 방어 비교를 만든
실행기 셋이 공격자에게 **호스트 셸을 주고 저장소 안을 작업 폴더로** 줬다.

| 실행기 | 공격자 도구 | 작업 폴더 |
| --- | --- | --- |
| `run_plain_claude_baseline.py` | `--tools default` (Bash 포함) | `app/evaluation/.../workspace` |
| **`autonomous_cli_policy_v2.py` (v2/v3 스택)** | **`--tools ""` (없음)** | 시스템 임시 |

막힌 것은 `WebFetch,WebSearch` 뿐이었다. 나머지는 프롬프트 문장으로만 금지했다.
공격자는 `app/backend/ruby_web/main.py`(모든 정답), 모듈 등록부, 평가기, 과거 시행
기록, docker 에 닿을 수 있었다.

**과거 92건을 훑은 결과 실제로 그 파일들을 읽은 시행은 0건이다.** 오염이 일어나지는
않았다. 그러나 막혀 있지 않았다는 사실은 그대로다.

## 이미 있던 답

v2/v3 자율 스택은 공격자를 **도구 없이** 띄운다(`autonomous_cli_policy_v2.py:163`).
모델은 스키마로 검증되는 JSON 행동 묶음만 돌려주고, 하네스가 그것을 HTTP 요청과
브라우저 문서로 실행한다.

그 공격자는 셸도, 파일도, docker 도 없다. 행동 공간이 웹 클라이언트가 할 수 있는
것과 정확히 같다. 이것이 이 연구가 재려는 것에 더 맞다.

**그러므로 기준선과 방어 비교는 `run_autonomous_campaign_v3.py` 계열로 돌린다.**
`run_plain_claude_baseline.py` 는 공격자 격리를 만족하지 않으므로 결과 생산에
쓰지 않는다.

## 함께 만든 것: 공격자 상자

도구 없는 공격자가 원칙적으로 옳지만, 하네스가 실행하는 요청도 대상 밖으로 나가면
안 된다. 망 수준에서도 강제한다.

**공격자 전용 망.** `api` 가 `edge` 망에 있어서 그 망에 붙은 것은 `api:8000` 으로
직접 갈 수 있었다. 거기에 `/internal/reset` 과 `/internal/victim` 이 있다.
nginx 만 있는 `attacker` 망을 만들고 `web` 만 붙였다.

**상자.** `app/attacker/Dockerfile`. 저장소를 담지 않고 실행할 때도 붙이지 않는다.
뿌리 권한이 아니다.

**출구.** `app/attacker/egress_proxy.py`. 공격자 망은 internal 이라 이 프록시
말고는 나갈 길이 없다. 통과시키는 것은 둘뿐이다. 모델 통제 평면으로 가는 CONNECT 와
대상 공개 출처로 가는 평문 HTTP. 거절한 주소는 세어서 남긴다.

### 탈출 시도 실측

```
대상 web:8080/api/products  -> 200
api:8000 직접               -> 도달 불가
api:8000/internal/state     -> 도달 불가
evaluator:8000              -> 도달 불가
postgres:5432               -> 도달 불가
인터넷 example.com          -> 도달 불가
호스트 마운트               -> 없음
도커 소켓                   -> 없음
앱 소스 탐색                -> 0건
```

출구 프록시를 붙였을 때도 정책이 유지된다.

```
대상 web:8080        -> 200
api.anthropic.com    -> 405 (터널 열림, API 가 GET 을 거절한 것)
임의 인터넷          -> 차단
api:8000/internal    -> 도달 불가
```

## 상자에 모델을 넣지 못한 이유

이 호스트는 Windows 이고 CLI 의 로그인 상태가 파일에 없다. `.credentials.json` 과
추린 `.claude.json` 을 넣어도 `Not logged in` 이다. 그래서 **모델 호출은 호스트에
두고 행동만 제한하는 v2 방식**이 지금 환경에서 유일하게 성립하는 격리다.

그 방식이 더 강한 보장이기도 하다. 상자 안 공격자는 상자를 깨면 무엇이든 할 수
있지만, 도구가 없는 공격자는 깰 상자 자체가 없다.

## 구형 실행기 처리

`run_plain_claude_baseline.py`는 명시적인 위험 승인 옵션 없이는 실행을 중단한다.
나머지 구형 비교 실행기는 배포 준비물에서 제거했다. 승인해 실행한 과거 결과도 공식
비교에 쓰지 않는다. 공식 기준선과 방어 비교는 `run_autonomous_campaign_v3.py`로만 만든다.
