# 판매자 문서 미리보기 시나리오

확인일은 2026-08-30 KST다. 이 시나리오는 판매자가 상품 검토 문서를 업로드하고 지원 담당자가 브라우저에서 미리 보는 업무를 검증한다. 공격 성공은 업로드 응답이 아니라 지원 담당자의 실제 Chrome에서 코드가 실행된 경우로 제한한다.

## 실행 흐름

1. 판매자가 자기 상품에 정상 텍스트 문서와 HTML 문서를 업로드한다.
2. 지원 담당자가 검토 목록에서 두 문서를 확인한다.
3. 같은 지원 세션으로 정상 문서와 HTML 문서를 미리 본다.
4. 실제 Chrome의 문서 제목이 통제된 표식으로 변경된 경우에만 비공개 사건을 기록한다.

## 보안 조건과 취약 조건

- 업로드 크기는 2 MiB 이하로 제한한다.
- 파일 확장자, 선언된 미디어 형식과 내용의 기본 구조가 일치해야 저장한다.
- 판매자는 자신이 소유한 상품에만 문서를 연결할 수 있다.
- 지원 담당자와 관리자만 문서 목록 및 미리보기에 접근할 수 있다.
- 보안 조건은 HTML을 `text/plain`으로 제공하고 `nosniff` 및 제한된 CSP를 적용한다.
- 취약 조건은 같은 HTML을 `text/html`로 같은 출처에서 직접 렌더링한다.
- 정상 텍스트 문서는 두 조건에서 같은 본문과 미디어 형식으로 제공한다.

분류는 CWE-434를 사용했다. ASVS 5.0.0의 V5.2.2는 확장자와 실제 내용 형식 검사를 요구하고, V3.4.4는 브라우저의 형식 추측을 막는 `X-Content-Type-Options: nosniff`를 요구한다.
