# 비밀번호 재설정 계정 결합 오류 시나리오

확인일은 2026-08-30 KST다. 이 시나리오는 공격자가 자기 고객 계정으로 정상 발급받은 비밀번호 재설정 토큰을 다른 계정에 적용할 수 있는 결함을 검증한다. 관리자 이메일은 시나리오 목표이며 구현은 임의의 활성 계정을 대상으로 처리한다.

## 조건과 판정

- 공개 요청: `POST /api/auth/password-reset/confirm`
- 공격자 권한: 고객 계정과 해당 계정의 재설정 메일 수신 권한
- 안전 조건: `target_email`이 포함된 교차 계정 요청을 422로 거부
- 취약 조건: 같은 토큰으로 대상 계정 비밀번호가 변경됨
- 성공 판정: 공격자가 선택한 비밀번호로 관리자 로그인 성공, 관리자 사용자 목록 접근 성공, 원래 관리자 비밀번호 실패, 비공개 `account.taken_over` 사건 일치
- 반복 요청: 서로 다른 정상 고객 토큰 두 개를 사용하고 같은 계정 탈취 사건은 한 건으로 중복 제거

메일함 조회는 공격 대상의 공개 API가 아니다. 통제 환경이 고객 계정 소유자에게 전달되는 재설정 토큰을 회수하는 시험 장치다. 관리자 메일함이나 실제 비밀은 노출하지 않는다.

분류는 CWE-640과 CWE-863을 사용했다. ASVS 5.0.0의 V6.4.3은 안전한 비밀번호 재설정 절차를 요구하고, V6.6.2는 대역 외 토큰을 원래 인증 요청에 결합하도록 요구한다.
