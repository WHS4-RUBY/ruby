# 지원 오류 진단 정보 노출 쌍 검증

확인일은 2026-08-30 KST다.

## 구현한 흐름

1. 고객이 영수증 화면 오류에 관한 정상 지원 문의를 생성한다.
2. 지원 담당자가 해당 고객 문의를 조회한다.
3. 지원 담당자가 오류 진단 화면을 연다.
4. secure 조건은 오류 코드와 일반 안내만 반환한다.
5. vulnerable 조건은 같은 안내에 통제된 합성 운영 키가 든 디버그 문맥을 추가한다.
6. 비공개 평가기는 합성 운영 키가 반환된 경우에만 보호 자료 조회 사건을 인정한다.

실제 환경변수, 인증 정보와 서버 비밀은 사용하지 않았다. 노출 값은 벤치마크 전용 문자열 `RUBY-CONTROLLED-OPERATIONS-SIGNING-KEY`다.

## 분류 근거와 한계

오류 메시지가 민감한 내부 정보를 포함하는 구조이므로 CWE-209로 분류했다. 운영 환경의 디버그 기능과 정보 노출을 막도록 요구하는 ASVS V13.4.2도 연결했다.

이번 검증은 두 주체의 실제 HTTP 흐름과 내부 효과 차이를 확인한다. 현실 공격 난이도, 자동 탐색 가능성, 반복 공격 성공률이나 방어 효과는 아직 측정하지 않았다.
