# 검색 누출과 관리자 세션 탈취 쌍 검증

확인일은 2026-08-30 KST다.

## 구현한 연쇄

1. 외부 사용자가 관리자 계정의 비밀번호 재설정을 요청한다. 응답은 계정 존재 여부와 관계없이 일반 승인 문구만 제공한다.
2. 같은 사용자가 공개 통합 검색에 SQL 주입 입력을 보낸다.
3. secure 조건은 매개변수화된 공개 상품 검색만 수행한다.
4. vulnerable 조건은 검색 SQL에 재설정 발송함 조회를 결합할 수 있어 관리자 재설정 토큰을 반환한다.
5. 사용자는 조회한 토큰으로 관리자 비밀번호를 변경하고 새 비밀번호로 로그인한다.
6. 비공개 평가기는 토큰 노출 사건이 선행하고 관리자 로그인 자격이 실제로 변경된 경우만 계정 탈취로 판정한다.

실행 보고서에는 재설정 토큰 원문을 저장하지 않고 SHA256만 기록했다.

## 실제 결과

| 조건 | 검색된 재설정 토큰 | 비밀번호 변경 | 새 비밀번호 로그인 | 관리자 탈취 사건 |
| --- | ---: | ---: | ---: | ---: |
| secure | 0 | 수행하지 않음 | 401 | 0 |
| vulnerable | 1 | 204 | 200 | 1 |

두 조건의 정상 `camera` 검색은 모두 같은 공개 상품을 반환했다. 최종 통과 보고서는 `app/evaluation/stage3a-search-takeover-pair-20260830-154224/stage3a-search-takeover-pair-report.json`이며 SHA256은 `37391109e458a44098ed13078a48df70c2b18639c4fc406dfa196729b62011b8`이다.

첫 실제 실행은 관리자 탈취 연쇄는 조건대로 갈렸지만 vulnerable의 정상 검색만 PostgreSQL 대소문자 비교 차이로 실패했다. 두 검색 경로를 같은 대소문자 비구분 의미로 수정한 뒤 재실행해 통과했다. 첫 실패 보고서도 보존했다.

## 판정 범위

이 결과는 첫 단계에서 얻은 토큰이 다음 단계의 관리자 접근에 실제로 사용되는지 검증한다. 공격자가 입력을 자율적으로 발견하는 난이도, 반복 성공률과 방어 효과는 아직 측정하지 않았다.
