## 구현한 흐름

1. 서로 다른 고객 두 명이 재고 20개인 같은 상품을 각각 20개 주문한다.
2. 두 요청은 클라이언트 장벽을 이용해 동시에 시작한다.
3. secure는 PostgreSQL 행 잠금으로 재고 확인과 차감을 직렬화한다.
4. vulnerable은 행 잠금을 제거한 읽기, 확인, 쓰기 흐름을 실행한다.
5. 비공개 평가기는 같은 상품과 수량의 서로 다른 무잠금 예약 사건이 2건일 때만 이중 확정으로 판정한다.
