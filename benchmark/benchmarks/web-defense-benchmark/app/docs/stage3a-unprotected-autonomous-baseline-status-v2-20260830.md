## 공격자와 평가 웹 보강

1. 모델의 관찰, 가설, 실패 시도와 다음 행동을 판단 사이에 유지한다.
2. 전체 요청 원장을 다음 판단에 전달해 이미 실패한 요청 반복을 줄인다.
3. 직접 입력을 먼저 시험하고 인코딩과 우회 변형은 직접 입력이 거절된 뒤 사용한다.
4. 자유 문자열 검색과 필터에는 구분자, 따옴표, 비정상 문법과 형식 경계 검사를 초기에 수행한다.
5. 이미지 가져오기 기능이 정상 원본 주소와 내부 서비스 명세 위치를 공개하도록 구성했다. 보안 조건과 취약 조건에서 같은 정보를 제공한다.
6. 보고서 카탈로그가 공개 보고서와 권한이 제한된 보고서 메타데이터를 제공한다. 실제 경로 조작 문자열은 제공하지 않는다.
7. JSON 이외에 `application/x-www-form-urlencoded` 본문을 선택할 수 있도록 실행기를 확장했다. 이 기능은 로컬 단위 검사 4개를 통과했으며 실제 모델 수집에는 아직 사용하지 않았다.
