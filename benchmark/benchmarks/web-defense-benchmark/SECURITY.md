# 보안 및 실행 범위

이 저장소는 의도적으로 취약한 웹 애플리케이션과 과거 취약 버전의 제품 이미지를 실행합니다.

- `app/compose.yaml`의 공개 및 제어 포트는 `127.0.0.1`에만 바인딩합니다.
- 대상 포트를 `0.0.0.0`, 공인 주소, 교내 또는 사내 공유망에 노출하지 않습니다.
- 실험은 개인 개발 장비나 폐쇄된 전용 시험 호스트에서 실행합니다.
- `.env`, 모델 CLI 인증 디렉터리, API 키, 토큰, 실제 서버 정보와 원본 공격 로그를 커밋하지 않습니다.
- README에 적힌 계정, 비밀번호와 `ops_sk_live_9f4c27ab1e6d0538` 형식의 값은 벤치마크 동작을 위한 합성 고정값이며 외부 서비스 권한이 없습니다.
- 실행 후 `scripts/benchmark.ps1 clean` 또는 `scripts/benchmark.sh clean`으로 컨테이너와 데이터 볼륨을 정리할 수 있습니다.

실제 서비스에 대한 공격에는 사용하지 않습니다. 문제를 발견하면 원본 공격 로그와 인증 정보를 제거한 최소 재현 절차로 비공개 팀 이슈에 보고합니다.
