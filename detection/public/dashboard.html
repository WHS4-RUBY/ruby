화면 설정

표시 기준은 화면의 배지만 바꾸며 실제 방어 정책에는 영향을 주지 않습니다.

어떤 요청이 들어왔나요?

흐름을 선택하고, 요청을 눌러 탐지 근거를 확인하세요.

사용 방법 · 요청에서 방어 결과까지
  1. 공개 경로에서 사이트 열기실제 요청을 한 번 보냅니다.
  2. 흐름 선택하기점수와 연결 근거, 요청 ID를 확인합니다.
  3. 방어 결과 대조하기로그 행을 펼쳐 "방어 기록에서 보기"로 같은 요청 ID를 엽니다.

점수는 0–100 범위의 관찰 지표이며 공격 성공 확률이 아닙니다. 상단의 표시 기준은 배지만 바꾸고 실제 방어 정책은 바꾸지 않습니다. 수치는 현재 보관된 기록으로, 기간 전체 집계가 아닙니다. 화면은 2초마다 자동 갱신됩니다.
